## About CDPaint

CDPaint is a pixel art painting app that brings a familiar MS Paint-style layout to a workflow focused on retro graphics. It runs across web and desktop environments, using Tauri and WebGL to support a responsive editing experience for sprite work, palette-driven artwork, and classic-style image creation.

It is especially useful for people working on Gen 3 ROM hacking, Game Boy Advance asset creation, and retro game development tasks. The tool combines simple drawing conventions with more specialized editing capabilities, making it easier to move from rough sketching to game-ready assets without switching between multiple apps.

- MS Paint-inspired interface and drawing workflow

## Usage

Start a new canvas, choose the drawing mode that fits your work, and begin placing pixels, shapes, or selections as needed. If you are preparing assets for a game project, use palette editing, sprite splitting, and image adjustments to shape the final output.

Typical workflow:
1. Open or create a canvas.
2. Switch between drawing and selection tools.
3. Edit the palette or reorder indices when working with indexed art.
4. Use tiled drawing mode for repeated patterns or structured layouts.
5. Export with the GBA or retro-focused tools when your asset is ready.
